# myrc

Minha configuração pessoal de desenvolvimento para macOS e Debian/Raspberry Pi.

## Instalação

Clone o repositório:

```bash
git clone https://github.com/duarch/myrc.git ~/dev/myrc
cd ~/dev/myrc
```

Instale os programas:

```bash
./bootstrap.sh
```

Configure o ambiente:

```bash
./install.sh
```

Abra um novo terminal.

Depois execute:

```bash
nvim
```

Na primeira execução o Lazy instalará automaticamente todos os plugins.
